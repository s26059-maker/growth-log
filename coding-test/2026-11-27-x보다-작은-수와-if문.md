# X보다 작은 수와 if문

> 📅 2026-11-27 · 코테 · 80점
> `#코테` `#반복문` `#조건문` `#Java`
> 입력값은 코드에 적는 게 아니라 실행할 때 밖에서 들어온다는 걸 이해하고, 숫자를 읽자마자 비교해서 한 줄에 공백으로 출력
> 🔗 [[백준 10871] X보다 작은 수](https://www.acmicpc.net/problem/10871)

## 문제 요약

수 N개와 X가 주어지면, X보다 작은 수만 입력받은 순서대로 한 줄에 공백으로 구분해서 출력한다.

```
입력
10 5
1 10 4 9 2 3 8 5 7 6

출력
1 4 2 3
```

## 입력은 누가 정할까

숫자는 코드에 적는 게 아니라 **실행할 때 밖에서 들어와.** 백준에 제출하면 문제 낸 사람이 정해둔 숫자가 들어가고, 내가 테스트할 땐 콘솔에 직접 쳐서 넣어.

계산기를 만든 사람이 누가 뭘 누를지 모르는 것처럼, 코드는 **어떤 숫자가 와도** 맞게 돌아가도록 짜야 해.

## 접근 방법

- `n`은 배열이 아니라 숫자 **개수**야. `sc.nextInt()`를 n번 불러서 하나씩 읽어
- 읽자마자 x와 비교해서 작으면 바로 출력해. 그래서 배열이 필요 없어
- "작은 수"라서 `<`를 써. x와 같은 수는 출력하면 안 돼
- 한 줄에 공백으로 출력해야 하니까 `println` 대신 `print(a + " ")`

**중요한 점**: `print`는 값을 하나만 받아. `print(a, " ")`처럼 쉼표로 넣으면 컴파일 에러가 나고, `+`로 붙여서 하나로 만들어야 해.

## 핵심 코드

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int x = sc.nextInt();

        for (int i = 0; i < n; i++) {
            int a = sc.nextInt();
            if (a < x) {
                System.out.print(a + " ");
            }
        }
    }
}
```

마지막 숫자 뒤에도 공백이 붙지만, 백준은 줄 끝 공백을 봐줘서 괜찮아.

출력할 숫자가 아주 많으면 `StringBuilder`에 모았다가 한 번에 출력하는 게 더 빨라.

```java
StringBuilder sb = new StringBuilder();
for (int i = 0; i < n; i++) {
    int a = sc.nextInt();
    if (a < x) {
        sb.append(a).append(' ');
    }
}
System.out.println(sb);
```

## 시간·공간 복잡도

- 시간 O(N): 숫자 N개를 한 번씩만 봐
- 공간 O(1): 숫자를 저장하지 않고 바로 버려

## 내가 놓쳤던 점

- 숫자 10개를 코드에서 정해야 하는 줄 알았음. 입력은 실행할 때 밖에서 들어옴
- `{` `}` 짝이 하나 모자라서 컴파일 에러가 났음
- 처음엔 `println`으로 한 줄씩 출력했고, `print(a, " ")`처럼 쉼표로 넣었음. 한 줄에 공백으로 출력하려면 `print(a + " ")`
