# 별 찍기와 이중 for문

> 📅 2026-11-26 · 코테 · 85점
> `#코테` `#반복문` `#이중반복문` `#Java`
> 줄마다 별 개수가 늘어나는 별 찍기를 repeat과 이중 for문 두 가지로 풀고, 자바 문자열 문법을 정리
> 🔗 [[백준 2438] 별 찍기 - 1](https://www.acmicpc.net/problem/2438)

## 문제 요약

N을 받으면 i번째 줄에 별을 i개 찍어.

```
*
**
***
```

## 접근 방법

- 바깥 반복: 줄을 1부터 N까지
- 각 줄에서: 별을 i개 찍고 줄 바꾸기

**중요한 점**: 자바는 `"*" * i`처럼 문자열에 숫자를 곱할 수 없어. 그건 **파이썬** 문법이야.

## 핵심 코드

**repeat 버전** (내가 낸 코드)

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();

        for (int i = 1; i <= n; i++) {
            System.out.println("*".repeat(i)); // "*"를 i번 반복한 글자
        }
    }
}
```

`repeat`은 **자바 11부터** 있어서, 백준에서 Java 11 이상으로 내야 해.

**이중 for문 버전** (다음 문제들을 위해 알아둘 것)

```java
for (int i = 1; i <= n; i++) {        // 바깥: 줄 (1 ~ N)
    for (int j = 1; j <= i; j++) {    // 안쪽: 그 줄에서 별 i개
        System.out.print("*");        // print는 줄을 안 바꿈
    }
    System.out.println();             // 별을 다 찍으면 줄 바꾸기
}
```

- `print`: 줄을 **안** 바꾸고 이어서 출력
- `println`: 출력하고 줄을 **바꿈**

## 시간·공간 복잡도

- 시간 **O(N²)**: 별을 1 + 2 + ... + N = 약 N²/2개 찍음
- 공간 **O(1)**

## 내가 놓쳤던 점

- 파이썬처럼 `"*" * i`라고 씀. 자바는 문자열 곱하기가 안 됨
- `println(...)` 끝 **세미콜론**을 또 빠뜨림
- 이중 for문 대신 `repeat`으로 풀어서, 이중 반복문 연습은 다음에 다시 하기
