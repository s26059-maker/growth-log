# A+B와 자바 입력 받기

> 📅 2026-11-23 · 코테 · 90점
> `#코테` `#입출력` `#Scanner` `#Java`
> 자바 Scanner로 입력받는 기본기를 A+B로 다시 익히고, int 범위와 빠른 입력까지 정리
> 🔗 [[백준 1000] A+B](https://www.acmicpc.net/problem/1000)

## 문제 요약

두 정수 A, B를 입력받아서 A+B를 출력해. (0 < A, B < 10)

## 자바로 입력받기

- `Scanner`: 입력을 대신 읽어주는 **직원**
- `System.in`: 입력이 들어오는 곳 (백준에서는 문제의 입력 데이터)
- `nextInt()`: 입력에서 **숫자를 하나씩** 꺼내줘. 띄어쓰기나 줄바꿈을 기준으로 끊어서, 부를 때마다 다음 숫자가 나와

**중요한 점**: 백준에 자바로 낼 때는 클래스 이름이 꼭 `Main`이어야 해.

## 접근 방법

`nextInt()`를 두 번 불러서 숫자 두 개를 꺼내고, 더해서 출력.

## 핵심 코드

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int a = sc.nextInt();
        int b = sc.nextInt();
        System.out.println(a + b);
    }
}
```

## 시간·공간 복잡도

- 시간 **O(1)**, 공간 **O(1)**: 숫자 두 개 읽고 한 번 더하면 끝이라, 입력 크기와 상관없이 항상 같은 시간이 걸려

## 알아둘 것

- `int`는 약 **21억**(2,147,483,647)까지만 담을 수 있어. 넘으면 값이 터지니까 큰 수는 `long`
- 입력이 몇십만 개씩 들어오면 `Scanner`가 느려. 그땐 더 빠른 `BufferedReader`를 써

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine()); // 한 줄 읽고 띄어쓰기로 자르기
        int a = Integer.parseInt(st.nextToken());
        int b = Integer.parseInt(st.nextToken());
        System.out.println(a + b);
    }
}
```

## 내가 놓쳤던 점

- `Scanner` 쓰는 법을 까먹었음: `new Scanner(System.in)`으로 만들고 `nextInt()`로 하나씩 꺼내기
