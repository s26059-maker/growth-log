# A+B - 3과 for문

> 📅 2026-11-24 · 코테 · 90점
> `#코테` `#반복문` `#Scanner` `#Java`
> 테스트 케이스 개수만큼 for문을 돌며 입력받고 출력하는 기본기를 익히고, 중괄호 실수를 바로잡음
> 🔗 [[백준 10950] A+B - 3](https://www.acmicpc.net/problem/10950)

## 문제 요약

테스트 케이스 개수 T가 먼저 들어오고, 그다음 A, B가 T줄 들어와. 줄마다 A+B를 출력해.

## 매번 쓰는 뼈대

```java
import java.util.Scanner;                     // 입력 도구 가져오기

public class Main {                           // 백준은 클래스 이름이 꼭 Main
    public static void main(String[] args) {  // 프로그램이 여기서부터 시작
        Scanner sc = new Scanner(System.in);  // 입력 받는 직원 준비

        // 여기에 코드 쓰기
    }
}
```

- `sc.nextInt()`: 부를 때마다 **다음 숫자**를 순서대로 꺼내줘. 줄이 바뀌어도 상관없어

## for문

```java
for (int i = 0; i < 5; i++) {
    System.out.println("안녕"); // 이 안이 5번 반복됨
}
```

- `int i = 0`: 0부터 세기 시작
- `i < 5`: 5보다 작은 동안 계속
- `i++`: 한 번 돌 때마다 1씩 증가

**중요한 점**: 중괄호 `{ }`가 없으면 **바로 아래 한 줄만** 반복돼. 반복할 줄이 여러 개면 꼭 중괄호로 묶어야 해.

## 접근 방법

T를 한 번 받고, T번 반복하면서 그 **안에서** A, B를 받아 더한 값을 바로 출력.

## 핵심 코드

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();

        for (int i = 0; i < t; i++) {
            int a = sc.nextInt();
            int b = sc.nextInt();
            System.out.println(a + b);
        }
    }
}
```

## 시간·공간 복잡도

- 시간 **O(T)**: 테스트 케이스 수만큼 반복
- 공간 **O(1)**: 숫자 몇 개만 씀

출력할 줄이 수만 개로 많아지면 `println`을 매번 부르는 게 느려져. 그땐 `StringBuilder`에 모았다가 한 번에 출력해.

## 내가 놓쳤던 점

- for문에 **중괄호**를 안 붙여서 `int a = ...` 한 줄만 반복되는 모양이 됨 (컴파일 에러)
- 출력을 반복문 **밖**에 둬서 테스트마다 출력이 안 됨
- `println(a + b)` 끝에 **세미콜론** 빠뜨림
