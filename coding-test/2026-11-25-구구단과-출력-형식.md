# 구구단과 출력 형식

> 📅 2026-11-25 · 코테 · 75점
> `#코테` `#반복문` `#출력형식` `#Java`
> 숫자와 글자를 섞어 출력하는 법과, 띄어쓰기 하나까지 맞춰야 하는 백준 출력 형식을 구구단으로 익힘
> 🔗 [[백준 2739] 구구단](https://www.acmicpc.net/problem/2739)

## 문제 요약

N을 입력받아서 N단을 `N * i = 결과` 형식으로 9줄 출력해.

## 숫자와 글자 섞어 출력하기

```java
int a = 3;
int b = 4;
System.out.println(a + " + " + b + " = " + (a + b)); // 3 + 4 = 7
```

- 글자는 `" "` 안에, 숫자 변수는 밖에 두고 `+`로 이어 붙여
- 띄어쓰기도 글자야. 출력에 띄어쓰기가 필요하면 **따옴표 안에** 같이 넣어
- 계산하는 부분은 **괄호**로 묶어. 안 묶으면 `"= " + a + b`가 계산이 아니라 글자로 이어 붙여져서 `= 34`가 돼

**중요한 점**: 백준은 띄어쓰기 하나만 달라도 "틀렸습니다"야. 예제 출력을 **한 글자씩** 비교하자.

```
틀림:  2*1=2
정답:  2 * 1 = 2
```

## 접근 방법

N을 받고, `i`를 **1부터 9까지** 돌리면서 `N * i = 결과`를 출력.
N이 몇이든 구구단은 항상 **9줄**이야.

## 핵심 코드

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();

        for (int i = 1; i < 10; i++) {
            System.out.println(n + " * " + i + " = " + (n * i));
        }
    }
}
```

IntelliJ 단축어: `psvm` + Tab은 `main` 메서드, `sout` + Tab은 `System.out.println()`

## 시간·공간 복잡도

- 시간 **O(1)**: N과 상관없이 항상 9번
- 공간 **O(1)**

## 내가 놓쳤던 점

- 반복 범위를 `i < n + 1`로 둬서 1부터 **N까지**만 돔. 구구단은 항상 **1부터 9까지**
- `*`, `=` 양옆 **띄어쓰기**를 빼먹어서 출력 형식이 틀림
- `println(...)` 끝 **세미콜론**을 또 빠뜨림
