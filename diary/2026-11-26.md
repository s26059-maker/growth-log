# 해커톤 멘토링과 사용자 관점

> 📅 2026-11-26 · 일기
> `#일기` `#해커톤` `#멘토링` `#UX`
> 해커톤 멘토링에서 "개발자 관점으로 만들었다"는 피드백을 받고, 메인 페이지에 몰린 기능을 처음 쓰는 사용자 기준으로 나누기로 함

## 오늘 한 일

해커톤 멘토링을 받았다. 멘토님이 우리 프로젝트의 부족한 점을 알려주셨는데, 팀원이 다 개발자라서 **개발자 관점**에서 프로젝트를 진행한 것 같다고 하셨다.

## 배운 점

돌아보니 우리는 무슨 기능이 있는지 다 알고 만들어서, 복잡한 화면에서도 하고 싶은 기능을 잘 찾아갈 수 있었다. 하지만 처음 쓰는 사람은 한두 페이지에 기능이 다 들어가 있으니 어디를 봐야 원하는 기능이 나오는지 모른다. 특히 메인 페이지에 다 넣어버린 게 컸다.

이미 아는 사람이 모르는 사람의 입장을 상상하지 못하는 걸 **지식의 저주**라고 한다. 길을 아는 사람한테는 복잡한 지도도 쉬워 보이는 것과 같다.

**중요한 점**: 성능 좋은 코드 아키텍처만큼, 사용자가 길을 잃지 않는 화면 구조도 중요하다.
